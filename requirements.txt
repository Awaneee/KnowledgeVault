# KnowledgeVault backend dependencies

# PyTorch / CPU-only note
# -----------------------
# sentence-transformers transitively depends on PyTorch.
# Without an explicit CPU pin, pip will download the default CUDA wheels
# from PyPI (~2 GB per wheel), even on CPU-only machines.
#
# Fix: pin torch to the CPU-only build from the PyTorch index.
# The +cpu local version suffix tells pip to only accept CPU builds.
# torch must be listed BEFORE sentence-transformers so pip resolves it first.
#
# If you are installing outside Docker, run:
#   pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
#
# The Dockerfile already passes --extra-index-url so Docker builds are
# always CPU-only automatically.
