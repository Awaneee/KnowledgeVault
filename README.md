# KnowledgeVault

KnowledgeVault is an intelligent knowledge management platform that automatically organizes and retrieves user knowledge.

## Current Features

- User Authentication (JWT)
- Categories
- Notes
- Attachments
- File Uploads
- PostgreSQL
- SQLAlchemy
- Alembic Migrations
- Repository-Service Architecture

## Tech Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT
- Pydantic

## Architecture

User
↓
FastAPI
↓
PostgreSQL
